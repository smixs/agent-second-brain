# Business Context

## Company Overview
ТОО «Industrial Project Company» (IPC) — аккредитованная экспертная организация по обследованию зданий и сооружений. Полный цикл: контракт → техзаключение/акт выполненных работ, с привлечением субподрядчиков (дефектоскопия, геодезия) под конкретные объекты. Директор и аттестованный эксперт — Сергиенко Александр.

Постоянных партнёров и клиентов на регулярной основе пока нет — объёмы разовые, от разных контрагентов через тендеры. Фиксированного списка компаний-целей ещё нет (в процессе составления). Приоритет 2026 года — выйти на постоянный поток объёмов через партнёрство с одной из крупных компаний рынка; название контрагента определяется по контексту записи, а не по заранее заданному списку.

Отдельно от IPC — TRONIX (со-фаундер, 10% доли в холдинге, оперативно ведёт TRONIX Shop): не CRM-бизнес с тендерами, см. references/classification.md, домен «TRONIX».

## Key Metrics
- Total CRM records: 0 (постоянных партнёров нет, карточки заводятся по мере появления тендеров/контактов)
- Active deals: нет — ни с кем переговоры пока не начаты
- Industries: строительство, промышленное и гражданское строительство, обследование зданий и сооружений
